# pierre.mesu.re

This is my personal website. It is still work in progress but the goal is to use it to gather all my past and future writings as well as information on all the non-professional projects I do.

This website is built with [Hugo](https://gohugo.io) and the [Congo](https://github.com/jpanther/congo) theme. It is hosted on [statichost.eu](https://www.statichost.eu).
